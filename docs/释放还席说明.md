# 释放还席说明（当日锁死）

| 项 | 值 |
|----|----|
| 锁定日期 | 2026-11-21 |
| 状态 | **已锁死（LOCKED）**，未经变更评审不得改走另一路径 |
| 钉死方案 | **甲路径：整笔事务释放（A_SINGLE_TX）** |
| 禁用方案 | 乙路径（释放影子稿 + 原子切换）——全仓不得出现，两套禁止混用 |
| 涉及接口 | `POST /api/release`、`GET /api/release/jobs`（路由照旧，登录会话沿用 Bearer Token） |
| 数据文件 | 仍挂本仓 `data/app.db`（SQLite 本机文件库），无外部依赖 |

## 1. 背景与根因

正式单点了释放，席位占用数纹丝不动、候补队列顶着满员。根因：释放服务原为空桩，
只向 `release_jobs` 登记任务单并写 `release_stub` 审计，**不改正式册 `bookings`、
不扣档期盘 `slots.booked`、不还容量**。接口回 200 形成“假绿”。

## 2. 钉死方案：甲路径（整笔事务释放）

同一连接、同一事务内四步同生共死，任一步失败整体 `rollback`，作废与扣减同滚：

1. **抢档锁**：锁键 `slot:{slot_code}`，与占位/确认/晋升同锁族。抢不到（两人同时抢释
   同一正式单）→ 仅向 `contention_log` 留争用痕并提交该痕，随后回 409，**业务零写**；
2. 锁内重读正式单，状态非「已确认」一律 409（含重复释放防护）；
3. `bookings.status` 改「已作废」（正式册真改，非角标）；
4. `slots_svc.return_seats()` 同事务把 `slots.booked` 扣回（档期盘真还，禁止扣负，
   扣负即抛错整笔回滚）；
5. 同事务写审计 `booking_release`（载荷含 `returned_seats`、`path:"A_SINGLE_TX"`），
   并落 `release_jobs` 状态「已释放」；
6. `commit`；任何异常 `rollback` 后重抛，`finally` 释放档锁。

**为何不选乙路径**：本仓写路径（hold/confirm/waitlist promote/slots）全部是
单连接单事务范式，库内无影子表；SQLite 单连接事务已提供所需原子性，引入影子稿
属另一套模型，混用必然产生双写分裂。故明确禁用，代码中不得出现 `release_shadow`
之类影子稿表或两阶段切换。

## 3. 五处同态口径（只改角标不算）

| # | 位置 | 释放后应然 |
|---|------|-----------|
| 1 | 正式册 `bookings` | 该单 `status='已作废'`，不再计入在册席 |
| 2 | 档期盘 `slots` | `booked` 实数扣减，空位回来 |
| 3 | 候补队 `waitlist` | 空位回来后候补中条目可 `/api/waitlist/promote` 晋升占位 |
| 4 | 对账灯 `/api/reconcile` | 盘面已订 == 在册正式席，新增 `released_seats` 列展示作废释放席，`all_ok=true` |
| 5 | 审计条 `audit_trail` | 一条 `booking_release`，载荷含还席数与路径标记 |

## 4. 争用语义

- 后到者：HTTP 409，`contention_log` 留痕（actor/lock_key/action='争用'）；
- 正式册、档期盘、审计、任务单均零写（测试 `test_double_release_contention_only_leaves_trace` 钉死）；
- 已作废单再次释放：409「禁止重复释放」，占用不二次扣减。

## 5. 偏航登记规则

- 实现或后续改动若偏离甲路径（出现影子稿/双写/先改角标不还席/绕过档锁/无测改文案），
  必须在本节登记为「释放还席偏航」，且**拒写**（不予合入）。
- 当前偏航记录：无。
